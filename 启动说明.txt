DjangoBlog 本地启动说明
============================

一、启动前准备
1. 确保 MySQL 已经启动。
2. 打开 PowerShell。
3. 把下面命令里的“你的MySQL密码”换成你本机 MySQL 的 root 密码。

二、第 1 个 PowerShell：启动 Django 后端
------------------------------------------------------------
cd D:\软工大作业\6-17-\src

$env:DJANGO_MYSQL_PASSWORD='你的MySQL密码'

python manage.py runserver
------------------------------------------------------------

启动成功后会出现类似：
Starting development server at http://127.0.0.1:8000/

注意：这个窗口不要关闭。

三、第 2 个 PowerShell：启动 Vite 前端
------------------------------------------------------------
cd D:\软工大作业\6-17-\src\frontend

# 首次安装依赖（已安装过可跳过）
npm.cmd install

# 启动 Vite 前端
npm.cmd run dev
------------------------------------------------------------

启动成功后会出现类似：
Local: http://127.0.0.1:5173/

注意：这个窗口也不要关闭。

如果 npm 报“禁止运行脚本”，优先使用 npm.cmd。
如果仍被 PowerShell 拦截，可以先执行：

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

四、浏览器访问
------------------------------------------------------------
http://127.0.0.1:8000/
------------------------------------------------------------

不要只打开 5173，页面入口是 8000。

五、第一次运行或数据库结构变更时
------------------------------------------------------------
cd D:\软工大作业\6-17-\src

$env:DJANGO_MYSQL_PASSWORD='你的MySQL密码'

python manage.py migrate

# 可选：刷新首页演示文章、分类、标签和侧边栏内容
python manage.py create_testdata
------------------------------------------------------------

六、停止项目
------------------------------------------------------------
分别打开两个正在运行的 PowerShell，按：
Ctrl + C

七、如果提示 Access denied
------------------------------------------------------------
说明 MySQL 密码不对。
修改这一行后重新启动：

$env:DJANGO_MYSQL_PASSWORD='你的MySQL密码'

八、如果端口被占用
------------------------------------------------------------
Django 可以换成 8001 端口启动：

cd D:\软工大作业\6-17-\src
$env:DJANGO_MYSQL_PASSWORD='你的MySQL密码'
python manage.py runserver 8001

然后浏览器访问：
http://127.0.0.1:8001/
