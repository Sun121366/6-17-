# 第 9-10 周维护说明（DjangoBlog）

本文件记录本期维护后的运行方式、配置项与验证方法，供复现与答辩演示使用。

## 1. 环境要求

- Python 3.10 及以上（本期在 Python 3.13.12 下验证通过）
- MySQL 8.0 及以上（本期在 9.6.0 下验证通过）
- Node.js 18 及以上，用于前端 Vite 开发服务器

## 2. 首次安装

```bash
cd src
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt  # macOS 编译 mysqlclient 需先 brew install mysql pkg-config

mysql -uroot -p -e "CREATE DATABASE djangoblog DEFAULT CHARACTER SET utf8mb4;"
export DJANGO_MYSQL_PASSWORD='你的数据库密码'
python manage.py migrate
python manage.py create_testdata     # 生成演示数据
python manage.py createsuperuser     # 按提示创建管理员
```

前端资源（首页会引用 Vite 的 `/src/main.js`，不启动前端时样式不完整）：

```bash
cd src/frontend
npm install
npm run dev                          # 5173 端口
```

## 3. 启动

```bash
cd src
export DJANGO_MYSQL_PASSWORD='你的数据库密码'
python manage.py runserver 8000
```

| 入口 | 地址 |
| --- | --- |
| 首页 | http://127.0.0.1:8000/ |
| 后台 | http://127.0.0.1:8000/admin/ |
| 运维助手（本期新增） | http://127.0.0.1:8000/servermanager/console/ |
| 健康检查 | http://127.0.0.1:8000/health/ |

运维助手仅限 `is_staff` 账号访问，非管理员访问返回 403。

## 4. AI 问答配置（本期重写）

`servermanager/api/commonapi.py` 中的 `ChatGPT` 类按 **OpenAI 兼容协议**调用，配置全部来自环境变量，不写进代码：

```bash
export OPENAI_API_KEY='sk-xxx'
export OPENAI_BASE_URL='https://api.openai.com/v1'   # 使用国内兼容服务时改成对应地址
export OPENAI_MODEL='gpt-4o-mini'                    # 换成服务方支持的模型名
```

三项缺任意一项时，页面会提示「未配置 OPENAI_API_KEY，AI 问答功能不可用」而不抛异常。接口不可达、返回体为空也各有独立提示。

## 5. 命令白名单

`CommandHandler` 只执行白名单内的命令，且在后台「命令管理」里登记过才能从页面下拉选择：

```
ls  pwd  whoami  df  du  uptime  date  echo  cat  head  tail  wc  uname
```

执行方式为 `subprocess.run(参数列表, shell=False)`，带 15 秒超时与 8000 字符输出截断；`rm -rf` 这类输入会被拒绝并提示「命令不在允许列表中」。

## 6. 文章目录插件

插件位于 `src/plugins/article_toc/`，通过 `src/djangoblog/settings.py` 的 `ACTIVE_PLUGINS` 启用：

```python
ACTIVE_PLUGINS = [
    'article_copyright',
    'reading_time',
    'external_links',
    'view_count',
    'seo_optimizer',
    'image_lazy_loading',
    'article_recommendation',
    'cloudflare_cache',
    'article_toc',   # 第 9-10 周新增
]
```

正文中出现 2 个及以上二级/三级标题时，插件自动在正文开头插入带层级缩进的目录，并给标题补 `id`；列表摘要页（`is_summary=True`）与已有锚点的标题会被跳过。

## 7. 测试

export DJANGO_MYSQL_PASSWORD='你的数据库密码'
python manage.py test
```

本期基线为 340 个用例全部通过，耗时约 78 秒。测试会创建独立的 `test_djangoblog` 库，因此**不要同时跑两个 test 进程**，否则会争用同一个测试库。

只跑本期新增的部分：

```
