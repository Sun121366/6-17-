## 三、逐项说明

### M1 ChatGPT 接入失效

**缺陷证据**：`src/servermanager/api/commonapi.py:20` 调用 `openai.ChatCompletion.create(...)`，这是 openai 0.x 版本的顶层接口；而 `src/requirements.txt` 锁定 `openai==2.54.0`，1.x 起 SDK 重构，顶层 `ChatCompletion` 已被移除。该调用必然抛出 `AttributeError`，被 `src/servermanager/api/commonapi.py:23` 的 `except Exception` 捕获后统一返回「服务器出错了」，功能实际不可用，但界面与日志均无明确报错。

**连带问题**：`src/servermanager/tests.py:19` 的 `test_chat_gpt` 只断言返回值非 `None`，异常降级后的「服务器出错了」同样满足该断言，导致缺陷长期未被测试发现。

**修复方案**：改用 `openai.OpenAI` 客户端；密钥、接口地址、模型名统一从环境变量读取（`OPENAI_API_KEY`、`OPENAI_BASE_URL`、`OPENAI_MODEL`），以兼容任何 OpenAI 协议的服务端点；补充请求超时、异常分类与明确的降级提示；`test_chat_gpt` 的断言改为校验错误分支与正常分支可区分。

### M2 运维命令执行缺少校验

**缺陷证据**：`src/servermanager/api/commonapi.py:49` 使用 `os.popen(cmd).read()` 执行命令串，命令内容直接来自数据库 `commands` 表，无白名单、无超时、无返回码判断，管理员误配或被篡改的记录可直接获得任意命令执行能力；且执行结果无长度上限。

**修复方案**：改为 `subprocess.run` 列表形式调用，禁止 shell 解析；命令白名单从配置读取；设置执行超时与输出截断；区分「命令不存在」「超时」「执行失败」「无权限」四类结果。

### M3 命令处理器导入期查库

**缺陷证据**：`src/servermanager/robot.py:28` 在模块级执行 `cmd_handler = CommandHandler()`，而 `CommandHandler.__init__`（`src/servermanager/api/commonapi.py:30`）立即执行 `commands.objects.all()`。模块导入即触发数据库查询，在迁移前、测试初始化阶段或数据库不可用时会阻断整个应用加载。

**修复方案**：改为首次使用时惰性加载，并支持显式刷新缓存。

### M4 运维助手后台页面

**现状**：`servermanager` 应用仅有模型（`commands`、`EmailSendLog`）、微信公众号机器人（`robot.py`）与两个 API 类，`views.py` 为空、`urls.py` 仅注册机器人回调、无任何前台入口，属于未完成模块。

**新增内容**：受登录校验的运维助手页面，含命令列表、命令执行与结果展示、AI 问答输入与回答展示；表单校验、错误提示、执行记录；后台注册调整。该页面同时作为 M1、M2 修复结果的验证入口。

### M5 文章目录（TOC）插件

**现状**：`plugins/` 下已有 8 个插件，均通过 `djangoblog/plugin_manage/` 的钩子机制接入，`src/djangoblog/settings.py:462` 的 `ACTIVE_PLUGINS` 控制启用列表。

**新增内容**：解析文章正文中的二级、三级标题，生成带锚点的目录并插入正文之前；列表摘要页不注入、已有 id 的标题沿用、少于 2 个标题不渲染、异常回退原文。

**与既有能力的关系**：`article_detail.html` 已有 `show_toc` + `get_markdown_toc` 的内置目录（默认关闭、需逐篇勾选）。本插件不重写它，而是提供零配置版本，检测到 `show_toc=True` 时让位，两者互补。

### M6 单元测试

为 M1–M5 逐项补充用例：SDK 调用成功与失败分支、白名单拒绝、超时分支、页面未登录跳转与登录后渲染、插件在有标题/无标题/重复标题下的输出。执行全量测试并与第7-8周基线对比。

## 四、明确不在本期范围

以下事项本次不做，避免影响行数统计与进度：修改 `blog`、`accounts`、`comments`、`oauth`、`djangoblog` 各应用既有业务逻辑；重构前端构建流程；引入新的第三方依赖（M1 所需 `openai` 已在依赖清单内）；改动数据库既有表结构（`servermanager` 沿用现有模型，不新增迁移）。
