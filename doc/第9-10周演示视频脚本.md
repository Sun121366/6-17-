# 演示视频录制脚本（第 6 班 17 组）

**硬性要求**：MP4 格式；视频开头必须出现小组编号与小组成员姓名。建议时长 8–10 分钟，全程 1080p 录制。

## 录制前准备（5 分钟）

1. 打开两个终端，先跑后端与前端（前端不启动首页样式会残缺，录像里很难看）：
   ```bash
   cd src && export DJANGO_MYSQL_PASSWORD='你的密码' && .venv/bin/python manage.py runserver 8000
   cd src/frontend && npm run dev
   ```
2. 浏览器窗口固定 1440×900 左右，关掉无关标签页、书签栏、通知。
3. 准备一个 `is_staff` 账号（演示页要用）和一个普通账号（演示权限拦截）。
4. 屏幕录制工具：macOS 用 QuickTime（文件 → 新建屏幕录制）或 OBS，输出 MP4。
5. 桌面背景清空，字体缩放到 125%，保证录像里代码可读。

## 第一段（0:00–0:40）组号与成员 —— 必须出现

开场用一个静态画面（PPT 首页或深色背景文字），停 5 秒以上，同时口头念出来：

> 「软件工程 6 班，第 17 组。小组成员：孙子杰、程光文、唐文龙、何动、吴政、唐磊。本次演示第 9-10 周对 DjangoBlog 开源博客系统的维护工作。」

这一屏要能截图取证，不要一闪而过。

## 第二段（0:40–2:00）维护前的项目与两个缺陷

1. 打开 GitHub 仓库，指出 master 分支的提交历史，说明本期在 DjangoBlog 基础上做维护。
2. 展示 `src/servermanager/api/commonapi.py` 的原始实现（可在提交历史里看 diff），讲两句：
   > 「原来的 AI 问答调的是 `openai.ChatCompletion.create()`，openai 2.x 已经删掉这个顶层接口，所以功能是彻底失效的——不是配置问题，是接口不存在了。」
   > 「命令执行原来是 `os.popen(cmd).read()` 拼字符串，等于把用户输入直接交给 shell，`; rm -rf` 这种就能打穿。而且没有超时、没有输出上限。」
3. 展示测试基线：终端里跑 `python manage.py test` 报 `assertEquals` 不存在——**这一步可以只贴截图**，不必直播等 78 秒。

## 第三段（2:00–4:30）修改缺陷：AI 接入与命令执行

1. 打开 `src/servermanager/api/commonapi.py`，逐块讲：
   - `ChatGPT.__init__` 从 `OPENAI_API_KEY` / `OPENAI_BASE_URL` / `OPENAI_MODEL` 读配置，密钥不进代码；
   - `_extract_content` 兜住返回体为空；
   - 未配置、不可达、空返回三类异常各有明确提示语。
2. 打开 `CommandHandler.execute`，讲三件套：`shlex` 解析 → 白名单比对 → `subprocess.run(列表, shell=False, timeout=15)`，输出截断到 8000 字符。
3. 打开 `src/servermanager/robot.py`，讲惰性加载：`_cmd_handler = None` + `get_cmd_handler()`，说明「原来模块一导入就查数据库，`migrate` 之前根本起不来」。

## 第四段（4:30–7:00）新增功能一：运维助手页面

这是最能拿分的部分，演示要熟练。

1. 浏览器打开 `http://127.0.0.1:8000/servermanager/console/`，先在**未登录**状态访问，展示跳到登录页；再用普通账号访问，展示 403「仅管理员可访问运维助手」。
2. 用管理员登录，完整演示三个区块：
   - **执行已登记命令**：下拉选 `df -h` → 提交 → 结果区出现磁盘表；
   - **直接执行命令**：输入 `echo hello django` → 得到回显；再输入 `rm -rf /tmp/anything` → 展示「命令不在允许列表中」的拦截；
   - **AI 问答**：输入「用一句话解释 Django 的 MVT 分别指什么」，若已配好 key 就现场出答案；没配好就展示「未配置 OPENAI_API_KEY」的提示，并说明设计上不抛异常。
3. 侧栏快速带过：白名单说明、当前已登记命令数。

## 第五段（7:00–8:30）新增功能二：文章目录插件

1. 打开 `src/plugins/article_toc/plugin.py`，讲 20 秒：读 `HEADING_PATTERN` 抓二三级标题、`is_summary` 跳过、已有 id 复用、`TOC_MIN_HEADINGS=2`、异常回退原文。
2. 打开 `settings.py` 的 `ACTIVE_PLUGINS`，指出只加了一行 `'article_toc'` 就生效——强调「插件机制的价值：不碰既有插件、不改渲染主流程」。
3. 浏览器打开一篇文章详情页，指着顶部的目录：层级缩进、锚点跳转。点一个三级标题，展示跳转。
